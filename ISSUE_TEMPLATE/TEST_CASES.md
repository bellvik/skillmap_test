2. Сверху в правом углу слева от "Выйти" появится имя пользователя.

## ID 
TC-SKILLMAP-004

## Приоритет
Высокий

## Заголовок
Построение карты профессии зарегистрированным пользователем

## Предусловия
1. Пользователь зарегистрирован 
2. Пользователь вошёл в свою учетную запись

## Шаги
1. Перейти на главную страницу сайта
2. Нажать кнопку **"Выбрать профессию"**
3. На странице **"Профессии"** нажать на кнопку **"Выбрать"** на карточке профессии **"Frontend-разработчик"**
4. Выбрать в разделе **"Ваш текущий уровень подготовки"** уровень **"Новичок"**
5. Выбрать в разделе **"Отметьте навыки, которые вы уже освоили"** **"HTML & CSS"**
6. Нажать на кнопку **"Построить карту"**

## Ожидаемый результат
1. Переход на страницу с картой профессии, сверху название **"Frontend-разработчик"**. 
2. Карточка **"HTML & CSS"** выделена зеленым и подписана **"✓ Освоено"**.
3. На карточках остальных навыков написано **"Не начато"**.
4. Сверху под названием **"Frontend-разработчик"** есть легенда с обозначением статусов карточек.
5. Над названием **"Frontend-разработчик"** кнопки **"К списку профессий"**, **"В мои карты"**, **"План обучения"**.

## Заголовок
Смена статуса с **"Не начато"** на **"В процессе"** на карточке навыка **"Git"** в карте профессии **"Frontend-разработчик"**

## Предусловия

## Шаги

2. Нажать на кнопку **"Открыть карту"** на карточке с названием **"Frontend-разработчик"**
3. Нажать на кнопку **"Подробнее о навыке →"** на карточке с название **"Git"**
4. Нажать на статус **"В процессе"** внизу открывшейся страницы навыка


## Ожидаемый результат
1. Страница навыка закроется
2. Карта навыка **"Git"** меняет цвет с прозрачного на желтый
3. Статус навыка меняется с **"Не начато"** на **"В процессе"** на карточке навыка **"Git"**

## Тестовые данные

## Шаги
1. Запустить локально сайт
2. Перейти по ссылке `http://localhost:5173/`

## Ожидаемый результат
1. Над почтой всплывает предупреждение, что пользователь с такой почтой уже существует
2. Пользователь не зарегистрирован повторно


Идеи для баг-репортов:
1. В моих картах карты с названием профессия 1, а не реальное название профессии
2. Пароль без какой-либо валидации, небезопасно

Идеи тест-кейсов:
1. создание карты профессии пользователем
2. удаление карты авторизованным пользователем
3. Изменение статуса с "В процессе" на "Освоено" и пересчет прогресса
негативные: 
4. Попытка регистрации/входа с пустыми обязательными полями


Добавьте проверку LocalStorage в шаги. Поскольку бэкенда нет, критически важно проверять, что данные действительно записались. Например, в TC-SKILLMAP-004 добавьте шаг: "Открыть DevTools -> Application -> LocalStorage и убедиться, что создан ключ skillmap_user_[id]_maps с корректной структурой".
